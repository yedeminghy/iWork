# 04 Streamable HTTP MCP 真实样本 — 填写示例

> 用途：演示 HTTP 传输 MCP 的留档格式。命名前缀必须是 `mcp-http-*`。
> 需要一个真实的 Streamable HTTP MCP 端点作为样本。

## 测试项与结果记录格式

| # | 测试项 | 操作 | 结果 | 记录要点 |
|---|---|---|---|---|
| 1 | 连接 | 配置 URL 并连接 | ✅ | 握手成功 |
| 2 | Tool Catalog | 枚举工具 | ✅ | 目录正确 |
| 3 | 成功调用 | 至少一次 | ✅ | 工具名与返回 |
| 4 | 取消或超时 | 断网/取消长调用 | ✅ | 状态干净 |
| 5 | 断开重连 | 服务端断开后重连 | ✅ | SSE 恢复、无重复会话 |
| 6 | 不自动重放 | 制造失败调用 | ✅ | `replayedCalls = 0` |

## 留档正文示例

```
2026-09-XX 17:00  连接：Streamable HTTP 握手成功，会话 ID 建立。
2026-09-XX 17:02  目录：枚举 8 个工具。
2026-09-XX 17:04  调用：query 工具返回正确结果。
2026-09-XX 17:06  超时：临时断网触发超时分类提示，恢复后状态干净。
2026-09-XX 17:09  重连：服务端重启后自动重连，SSE 订阅恢复，无重复订阅。
2026-09-XX 17:11  重放检查：失败调用未重放，计数为 0。
结论：PASSED
```

## 对应 user-evidence.json 片段

```json
{
  "transport": "STREAMABLE_HTTP",
  "status": "passed",
  "replayedCalls": 0,
  "evidenceId": "ev_5d1e04a8b639"
}
```

> ⚠️ JSON 中不要写 MCP 端点 URL（可能含内网地址，导入器会按私有信息拒绝）；
> 端点地址只留在本地留档里。
