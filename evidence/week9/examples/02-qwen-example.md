# 02 Qwen Provider 真实样本 — 填写示例

> 用途：演示 Qwen 测试的留档内容格式。命名前缀必须是 `qwen-*`。
> 测试项与 DeepSeek 完全一致（五项 + 泄漏检查），以下仅列差异点。

## 与 DeepSeek 的差异点

1. Qwen 凭据在设置页单独录入，切换 Provider 后确认会话上下文不串线。
2. 错误凭据测试建议分别验证「密钥错误」与「模型名不可用」两种分类。
3. 留档正文建议额外记录一行 Provider 切换前后的会话完整性。

## 测试项与结果记录格式

| # | 测试项 | 结果 | 记录要点 |
|---|---|---|---|
| 1 | 正常流式 Chat | ✅ | 逐 token 渲染 |
| 2 | Tool Calling | ✅ | 工具名与回填 |
| 3 | 取消 | ✅ | 状态归位 |
| 4 | 重试 | ✅ | 重试成功 |
| 5 | 错误凭据/不可用模型分类 | ✅ | 两种错误均稳定提示 |
| 6 | 密钥泄漏检查 | ✅ | 界面/日志/诊断三处 |

## 留档正文示例

```
2026-09-XX 15:30  流式 Chat：4 轮对话正常。
2026-09-XX 15:33  Tool Calling：调用本地时间工具成功。
2026-09-XX 15:35  取消/重试：均正常。
2026-09-XX 15:38  错误凭据：401 分类提示；改用不存在的模型名：返回"模型不可用"分类。
2026-09-XX 15:41  切换检查：DeepSeek→Qwen 切换后历史会话保持，无串线。
2026-09-XX 15:43  泄漏检查：三处无明文。
结论：PASSED
```
