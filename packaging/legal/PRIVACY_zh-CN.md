# iWork 隐私政策

版本：1.0  
更新日期：2026年9月2日  
生效日期：2026年9月2日

杭州烛光鱼有限公司（以下简称“我们”）是 iWork 的个人信息处理者。iWork 是一款本地优先的 Windows AI Agent 桌面应用。本政策说明 iWork 如何处理您的个人信息及其他数据，以及您如何行使相关权利。

在安装或使用前，请完整阅读本政策。涉及模型服务商、远程 MCP 服务等第三方处理的，我们会在相应功能或本政策中说明；请您同时阅读所选第三方的隐私规则。若您不同意，请勿向相关功能提供个人信息。

## 一、适用范围

本政策适用于 iWork 1.0 Beta 桌面软件。您通过浏览器、电子邮件或其他渠道主动联系公司，以及第三方模型服务商、MCP 服务自身独立处理数据的活动，可能另受相应渠道或第三方规则约束。

本版本不提供 iWork 云端账户、团队云同步或无人值守云端任务。我们不会仅因您安装或启动软件而自动收到您的聊天内容或本地文件。

## 二、我们如何处理数据

### 1. 本地运行数据

为提供会话恢复、Agent 执行、工具审批、MCP/Skill 配置、故障恢复和安全审计功能，软件会在您的设备上处理并保存下列数据：

- 您输入的聊天内容、附件或文件引用；
- 模型回复、工具参数和结果、审批决定、结构化运行事件；
- Provider、MCP、Skill、工作区及允许访问的文件根目录配置；
- 应用版本、运行状态、错误码、耗时及资源计数等本地诊断信息。

这些数据默认保存在本机应用数据目录中，未经您的主动操作不会上传给我们。您可在应用提供的功能中删除相应记录；卸载程序默认保留应用数据，以支持重装恢复。如需彻底删除，应先使用应用内删除功能，或在退出软件后按产品指引清理应用数据目录。

### 2. 凭据

当您配置模型服务商或需要认证的 MCP 服务时，软件会处理 API 密钥、访问令牌等凭据。受支持的凭据由 Electron 调用 Windows 安全存储能力加密保存；Renderer 页面不能读取明文凭据。为完成一次请求，必要凭据可在本机 Host 的受控内存中短暂使用，并在超时、使用后或会话结束时清理。

凭据保存至您删除、替换相关配置或清理应用数据。请勿在聊天、日志、Skill 文本或反馈材料中粘贴密钥。

### 3. 模型服务商请求

当您明确选择并调用 DeepSeek、Qwen 或以后由您配置的其他模型服务商时，为生成回复，软件会将请求所必要的聊天内容、系统指令、工具定义、附件内容或上下文发送到所选服务商的接口。实际发送范围取决于您的输入、会话上下文、功能选择和服务商能力。

此类数据由您选择的服务商按照其条款和隐私政策处理。当前版本不通过我们的云服务器中转模型请求。请勿向模型服务商发送您无权处理或超出业务必要范围的个人信息、商业秘密及其他敏感数据。

### 4. MCP 服务和 Skill

当您启用 MCP 工具或 Skill 时，软件会在权限和审批规则允许的范围内处理工具参数、文件内容和执行结果：

- 本地 STDIO MCP 和本地 Skill 通常在您的设备上运行，但其子进程可能按自身实现访问本地资源或网络；
- 远程 HTTP MCP 会接收完成调用所需的参数和上下文；
- 软件不会因为 Skill 文本或 `allowed-tools` 声明而自动授予执行权限，涉及受控能力仍需通过权限判断或您的明确审批。

MCP、Skill 的发布者或运营方可能是独立的个人信息处理者。安装或启用前，请核验其来源、权限需求和隐私规则。

### 5. 诊断和反馈

软件当前不默认启用遥测，也不会自动向我们上传崩溃报告或诊断包。诊断导出仅在您主动操作时在本地生成，并采用允许字段清单，设计上排除聊天正文、提示词、工具参数和结果、凭据、请求头、Cookie、推理内容、环境变量及绝对路径等信息。

只有当您通过另行提供的联系渠道主动提交诊断包、截图或反馈时，我们才会收到相应材料。提交前请再次检查并删除不必要的个人信息或敏感数据。我们仅为定位问题、提供支持和改进产品处理该材料，保存期限原则上不超过问题关闭后 180 日；如法律另有要求或双方另有约定，从其规定。

## 三、处理目的、方式和保存期限

我们遵循合法、正当、必要和诚信原则，仅在实现明确目的所需的最小范围内处理数据：

| 数据类别 | 处理目的 | 处理位置或接收方 | 保存期限 |
| --- | --- | --- | --- |
| 会话、运行事件和本地配置 | 提供核心功能、恢复状态和安全审计 | 您的设备 | 至您删除、清理应用数据或达到产品配置的保留期限 |
| Provider/MCP 凭据 | 连接您选择的服务 | 您的设备；调用时临时提供给目标服务 | 至您删除或替换配置；临时内存按会话或超时清理 |
| 模型请求内容 | 生成模型回复或工具调用 | 您选择的模型服务商 | 由对应服务商规则决定 |
| 远程 MCP 请求内容 | 执行您选择的 MCP 工具 | 您配置的 MCP 服务 | 由对应服务运营方规则决定 |
| 您主动提交的诊断和反馈 | 问题定位、支持和产品改进 | 杭州烛光鱼有限公司 | 原则上至问题关闭后 180 日 |

我们不会以默认自动遥测为目的收集数据，也不会将个人信息用于与上述目的无关的自动化营销。

## 四、委托处理、共享、转让和公开披露

1. 我们不会出售您的个人信息。
2. iWork 不会默认把本地数据共享给我们。您主动调用模型服务商、远程 MCP 或其他第三方服务时，相应数据会由您的设备直接发送给该第三方；这属于您选择的功能数据流，并非由我们取得后再行转售。
3. 如未来需要委托服务商代表我们处理个人信息，或发生合并、分立、资产转让等导致个人信息转移的情形，我们将依法告知并要求接收方继续履行相应义务；依法需要取得同意的，我们会另行取得。
4. 除法律法规要求、履行法定义务或应对紧急安全情形外，我们不会公开披露您的个人信息。依法需要取得单独同意的，我们会在披露前取得。

## 五、数据出境

DeepSeek、Qwen 或您配置的 MCP 服务可能提供不同地区的接口。您应优先选择满足所在组织和数据所在地要求的区域。若数据将被传输至中国大陆境外，我们会在属于我们决定处理活动的范围内依法履行安全评估、认证或标准合同等适用要求，并在法律要求时向您告知境外接收方、处理目的、方式、数据种类和行使权利方式，取得单独同意。

Beta 期间，在法务和安全负责人完成具体服务商、区域及数据类别评估前，请勿通过境外接口处理个人信息、重要数据或受组织限制的数据。

## 六、敏感个人信息和未成年人信息

请不要在非必要情况下输入生物识别、医疗健康、金融账户、行踪轨迹、精确定位、身份证件、未成年人信息等敏感个人信息。如业务确有必要，应先确认合法性基础、充分必要性、严格保护措施及是否需要单独同意，并仅提供最小范围。

iWork Beta 不面向不满十四周岁的未成年人。若监护人发现未成年人信息被不当处理，请通过本政策列明的方式联系我们核实和删除。

## 七、安全措施

我们采取与风险相适应的措施保护数据，包括操作系统安全存储、最小化 Renderer IPC、回环访问控制、权限和审批机制、固定文件根目录、安装资源完整性校验、诊断字段白名单以及凭据和敏感内容扫描。

但任何系统均无法保证绝对安全。您应及时安装安全更新，保护 Windows 账户和设备，审慎配置第三方服务，并避免授予超出任务所需的权限。如发生或可能发生个人信息泄露、篡改、丢失，我们将依法采取补救措施并履行通知或报告义务。

## 八、您的权利

在适用法律规定的范围内，您有权查阅、复制、更正、补充、删除相关个人信息，撤回基于同意的处理，注销配置，限制或拒绝特定处理，并要求说明本政策。撤回同意不影响撤回前处理活动的效力。

对于仅保存在您设备上的数据，请优先使用应用内功能或本地数据清理指引操作。对于您主动提交给我们的反馈或诊断材料，可通过下列联系方式提出请求。我们会核验请求人与数据主体的关系，并在法律规定期限内处理。

## 九、政策更新

我们可能因功能、数据流或法律要求变化而更新本政策。发生重大变化时，我们会通过新版本、安装界面或应用内提示向您告知；依法需要重新取得同意的，我们将在相关处理开始前取得。
